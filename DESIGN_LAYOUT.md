## Color Palette

### Primary Colors:
- **Primary Blue:** `#5B6CF2` (from-primary)
- **Accent Blue:** `#3D63FF` (to-accent-blue)
- **Gradient:** `from-primary to-accent-blue`

### Text Colors:
- **Dark Text:** `text-text-primary` / `text-gray-900`
- **Light Gray:** `text-gray-600`
- **Very Light:** `text-white/70`

### Background Colors:
- **White:** `bg-white`
- **Light Gray:** `bg-gray-50`
- **Dark (Footer):** `bg-text-primary` (dark navy/black)

## Responsive Behavior

### Mobile (< 768px):
- Single column layouts
- Full-width cards and sections
- Stacked footer information
- Simplified navigation

### Tablet (768px - 1024px):
- 2-column grids
- Medium padding and spacing
- Optimized typography sizes

### Desktop (> 1024px):
- Multi-column layouts
- Enhanced spacing and breathing room
- Full animation effects
- Hover states activated
